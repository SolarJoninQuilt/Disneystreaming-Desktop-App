## Getting started

1. Download the zip archive to your computer.
2. Extract the contents of the zip file.
3. Open the folder where the files were extracted and locate the file named `setup`.
4. Double-click `setup` to start the program.

---

## What it does

The highlights:

* Every file the program needs in order to run shares a folder with `setup`.
* The program opens when you run `setup` from the folder the archive unpacked.
* No installer runs on the side; the archive is a plain zip.
* The `setup` file does not leave a separate uninstaller entry behind
* The first start may take a moment; later starts will be faster.
* Beside `setup` sit the files required for it to run.

## About

This archive contains the Windows build of the program. Extract the files and run `setup` to start.

One extracted folder serves one user. A second user extracts their own copy under their account.

Current builds of the program are published in this archive. Extract the contents and run the file named `setup` to start using the program.

---

## Requirements

A modest PC is enough:

* Leave disk room for the archive plus a little extra beside it.
* All of the unpacked files have to stay in a single folder.
* Whoever runs it must be allowed to write in the folder.
* A standard user account is enough. No admin rights are needed.

## Common questions

<details><summary>Can I move the folder?</summary>

Yes, as long as you move the whole folder and start `setup` from the new place.
</details>

<details><summary>How do I take the unpacked copy off the computer?</summary>

Throw away the folder that extraction created.
</details>

<details><summary>A long chain of directory names made the start fail. How do I shorten that path?</summary>

The path shrinks when the folder name is short and the extract sits near the root of the drive.
</details>

<details><summary>I know the Windows version and the click that failed. Is the report bigger than that?</summary>

No. An issue carrying that click and that Windows version is the report.
</details>
